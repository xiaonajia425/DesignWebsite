04 · RADIUS

圆角规范

以克制、一致、可解释的圆角体系定义控件边界与容器层级，覆盖组件映射与嵌套关系。

Radius TokenComponent MappingNested RadiusAuto Layout
RADIUS SCALE

圆角基础变量

使用 0、2、4、6、8、12、999 七档标准值，不引入用途重叠的 10px 圆角。

radius/none0px连续结构、表格
radius/xs2px标签、状态块
radius/sm4px按钮、输入框
radius/md6px卡片、菜单
radius/lg8px弹窗、重点容器
radius/xl12px特殊强调区域
radius/full999px头像、胶囊标签

不使用 10px：它位于 8px 与 12px 之间，缺少独立语义，会增加判断成本。

03 / SHADOW

投影样式

投影强度与界面层级对应。越临时、越需要聚焦的内容，投影等级越高。

静态小卡片分隔、轻微抬升Shadow/XS
可点击容器卡片、按钮组Shadow/SM
悬浮工具菜单、选择器Shadow/MD
对话框抽屉、浮层Shadow/LG
关键通知最高层级Shadow/XL
Glass / Background Blur

填充、描边、模糊与投影共同建立毛玻璃层级。

  • 先使用背景与描边建立结构
  • 再通过投影强化前后层级
  • 为不支持模糊的环境提供降级方案
06 · COMPONENTS

按钮 Button

用于触发即时操作。通过统一类型、尺寸、内容、状态和组合方式，建立稳定且可预测的操作层级。

Button 组件Button Group 组件
TYPE & SIZE

类型与尺寸

一个区域最多一个 Primary。Danger 表达风险语义，不参与普通按钮的视觉层级排序。

Primary

当前区域主要操作

Secondary

重要性低于主操作

Text

行内及卡片辅助操作

Danger

高风险或不可逆操作

STATES

内容与交互状态

按钮文案优先使用“动词”或“动词 + 对象”，默认使用 Medium 尺寸。

✓ Do

一个操作区域只保留一个 Primary；危险操作说明后果。

× Don’t

不要重新绘制按钮或用颜色覆盖现有语义。

07 · ICON GUIDELINES

图标 Icon

基于 Remix Icon 4.9.1，统一 24 × 24 网格、语义颜色、尺寸与替换方式，覆盖常用 B 端场景。

图标资产110 个独立 Componenticon/primarySwap instance
SIZE & OPTICAL ALIGNMENT

尺寸与光学校准

所有源组件保留 24 × 24 基准网格。使用时按场景等比缩放，不拉伸路径。

12 px极密辅助信息
14 px紧凑表格
16 px默认控件
20 px导航 / 按钮
24 px标题 / 独立入口
32 px展示型图标

推荐：用容器统一对齐

图标位于固定点击容器中，由 Auto Layout 负责居中与间距。

避免：为“看齐”而拉伸或改路径

× 非等比缩放　× 手动挪动节点　× 混用 16 / 20 / 24 px

需要视觉校准时，调整外部容器，而不是修改源图标。
08 · COMPONENTS

输入框 Input

用于接收单行文本数据。通过统一尺寸、内容、状态、图标与错误反馈，建立清晰、稳定且可访问的录入体验。

Input/StandardInput/Error42 Variants
STATES

状态

状态由交互或校验结果驱动。Focus 使用 2px 视觉强调，Error 使用危险语义边框与状态图标。

SIZE & TOKEN MAPPING

尺寸与变量映射

三种高度与横向内边距均绑定 Input 组件变量，默认使用 Medium。

  • Placeholder 不替代 Label
  • 颜色与图标不是唯一反馈
  • Disabled 与 Read-only 语义不同
