# 大屏静态资源

本目录包含 Figma 静态资源交付页导出的 32 项资源、用户补充的顶部阶段数据框 1 项，以及从原始顶部节点补导的 2 项延伸光效，共 35 项。

- `source/`：Figma 原始导出母版，包含 27 个 SVG 和 5 个 PNG。
- `runtime/`：页面实现直接引用的当前版本；其中 `header-phase-frame.svg` 为用户补充的顶部数据框，其余资源与母版格式一致。
- `manifest.json`：资源编号、文件名、尺寸、Figma Node ID、文件体积和 SHA-256。

## 使用约定

- 页面代码优先引用 `runtime/`。
- 不直接修改 `source/`；资源更新应从 Figma 重新导出。
- SVG 优化后必须保留 `viewBox` 并执行视觉回归。
- PNG 后续可在构建流程转换为 WebP/AVIF，但需保留 PNG 回退。
- A03 已排除动态状态灯；状态灯、文字、数字、图表和动画由代码实现。
- 中央拓扑设备和拓扑事件标记不在本次静态资源范围内。

完整设计与实现约定见项目根目录的《大屏页面还原基线.md》。
